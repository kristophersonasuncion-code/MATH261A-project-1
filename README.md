# Socioeconomic Hardship and Chronic Absenteeism in California Public School District (2024-2025)

Kristopher Asuncion

## Project Overview

This project applies a simple linear regression to research if there is an association between student chronic absenteeism and student poverty for California public school districts in the 2024-2025 academic school year. 

## Data 

The data comes from the California Department of Education Data and Statistics website (https://www.cde.ca.gov/ds/). 

* Chronic Absentism Data:  https://www.cde.ca.gov/ds/ad/filesabd.asp
* Free or Reduced-Price Meal (Student Poverty) Data:  https://www.cde.ca.gov/ds/ad/filessp.asp
